Chapter 1: Getting Started

Welcome! In this chapter, you will learn how to download, install, and run MSH.

1. Requirements

  • Linux (Any Distribution)
  • Bash
  • Git
  • curl
If you are using Windows, use a virtual machine or install Git Bash.

2. Clone the Repository

git clone https://github.com/MEHRAD111/Msh.git

3. Open the Project Folder

cd Msh

4. Choose Your Branch

git switch Rolling-Release

or

git switch Stable
The Rolling-Release (SRR) branch contains the newest features, but it is experimental and may contain bugs.

The Stable branch is fully tested and recommended for daily use.

5. Run MSH

bash MSH-SRR.sh

or

bash MSH-Stable-V3.sh

Congratulations!

You have successfully started MSH. Continue to Chapter 2 to learn about the built-in tools.
