Chapter2:Msh Tools Review

Welcome! In this chapter, you will learn about important MSH tools, including:

MPKG: MSH Plugin/Package Manager

MPKG is a powerful package manager for managing, downloading, installing, enabling, and disabling MSH plugins. You will learn more about it in the next chapter.

MshBackuper

MshBackuper (now a plugin based on BackuperX) is a simple and powerful tool for backing up your important files and folders.

MshCenter: MSH Update Checker

MshCenter is a utility for checking MSH updates.

Backup Config

A built-in script for backing up your configuration files (such as .config, .docker, and others).
